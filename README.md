# Sitio profesional — frossi.com.ar

Sitio estático HTML/CSS/JavaScript, sin dependencias externas ni hosting adicional. Preparado para GitHub Pages.

## Publicación

1. Descomprimir el ZIP.
2. Reemplazar los archivos del repositorio `Poyo10/frossi` por el contenido de esta carpeta (mantener `CNAME`).
3. Hacer commit y push a la rama que publica GitHub Pages.
4. Verificar `https://www.frossi.com.ar` y que GitHub Pages mantenga habilitado HTTPS.

`privacidad.html` se conserva como estaba en el repositorio original. Conviene revisar sus textos entre corchetes antes de utilizarla como política vigente.
